# Response Style Guidelines

## Conciseness

- Keep responses SHORT and to the point
- Use 4-5 bullet points maximum for summaries
- Each bullet point should be ONE sentence
- NO detailed explanations unless explicitly requested
- NO verbose descriptions of what was done

## Summary Format

When completing work, use this format:

**Done:**

- Changed X in file Y
- Fixed Z issue
- Added W feature
- Updated V configuration

That's it. No introductions, no detailed explanations, no emoji unless appropriate.

## When to be Detailed

ONLY provide detailed explanations when:

- User explicitly asks "explain" or "why"
- Complex architectural decisions need justification
- User is confused and needs clarification

## Default Mode

- Concise
- Direct
- Action-oriented
- Minimal text
